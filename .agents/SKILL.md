 # 프로젝트 개요
- 본 프로젝트의 개발은 4일간 진행될 간단한 사이즈의 프로젝트임을 명시
- 따라서 지나치게 복잡한 구조를 지양하고 심플한 구조를 지향할 것
- 너무 방대한 기능보다는 핵심 기능에 집중할 것

# 개발자 역량
- 비전공자로, 개발을 처음 접해보는 상태임
- 따라서 코드 가독성을 최대한 높이고 직관적인 구조를 지향할 것
- 기능별로 간단한 주석을 달아줄 것
- 개발 도구 사용에 미숙하므로, 실행 및 디버깅이 용이한 구조로 작성할 것

# Always DO
- 요청 사항에 대해서는 항상 먼저 명확히 이해했는지 확인 후 implementation 단계로 진입 할 것
- 개발자의 허락 또는 요청이 있기 전에는 임의로 코드를 작성하지 않을것
- 기능 개발 및 오류 개선 후 관련하여 진행한 내용과 진행하지 못할 사항을 간략하게 정리하여 전달 후 AGENTS.md와 PROGRESS.md 파일에 업데이트 할 것
- 코드 수정사항에 대해서는 항상 먼저 개발자에게 공유 후 수정을 진행할 것 (어떤 파일에 몇 번째 라인에 해당되는 내용인지 필수로 전달)

# MUST NOT DO
- 진행 상황을 정리하지 않고 기능 개발만 진행하는 행위
